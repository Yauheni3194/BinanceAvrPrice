# Приложение которое по расписанию забирает среднюю цену торговой пары у биржи Binance

Приложение работает на "Java 21", "Gradle 8.7" и "PostgreSQL 17". 
Включает в себя REST API для Postman

## Как запустить на любом компьютере:

### 1. Требования
На компьютере должен быть установлен и запущен "Docker Desktop".

### 2. Запуск проекта
Откройте терминал/консоль в папке проекта и выполните команду:
"docker compose up --build -d"

### 3. Примечания к работе 
* Для работы в браузере приложение будет доступно по адресу: "http://localhost:8080"
* При работе с Postman приложение принимает:
--GET-запрос для получения задачи по адресу: "http://localhost:8080/rest/task/{id}" где {id} - номер задачи;
--POST-запрос для создания задачи по ардесу: "http://localhost:8080/rest/task". В теле запроса должен быть JSON:
{
    "text": "Текст для редактирования",
    "language": "ru"
}
* Посмотреть логи работы планировщика: "docker compose logs -f spring-app"
* Остановить проект: "docker compose down -v"
